Quiet Camera は、授業中のシャッター音をきっかけに個人で開発したカメラアプリです。4:3の大きなプレビューで画角を確かめられます。撮影のたびに消音処理を自動で行い、選択中のカメラが提示する最大の写真寸法を要求して、「写真」アプリへ保存します。ソースコードとして公開しているので、使うにはXcodeでビルドして自分のiPhoneにインストールしてください。

> [!IMPORTANT]
> **無音になることは保証できません。** 48MPで保存できても、純正カメラと同じ画質になるとは限りません。動作確認も特定の端末に限られています。使う前に[しくみと制約](#しくみと制約)をお読みください。

## 作った理由

授業中に、教授から「シャッター音を消してほしい」と言われたのが始まりです。

Appleの説明によると、iPhoneのシャッター音は消音モードにすると消せます。ただし、一部の国や地域ではシャッター音を消音できないとされています（[Appleサポート](https://support.apple.com/guide/iphone/adjust-the-shutter-volume-iph6cfaf98b6/ios)）。日本では、たとえばSoftBankのiPhone向けFAQで、マナーモードにしても消音されないものとしてカメラのシャッター音が挙げられています（[SoftBank よくあるご質問](https://www.softbank.jp/support/faq/view/12722)）。細かな挙動は端末や地域によって異なります。それでも、こうしたiPhoneでは、マナーモードにするだけでは静かに撮影できません。

試した無音カメラアプリでは、画質に満足できませんでした。撮影音を抑えることと、できるだけ高い解像度で保存することを両立したくて、自分で作ったのがこのアプリです。

画質の評価は個人の使用経験によるもので、他のアプリとの比較試験は行っていません。

目的は、静かな場所で周りの迷惑にならないことです。撮影が許可されている場所で、被写体のプライバシーや授業・施設のルールを尊重して使ってください。

## できること

- **大きなプレビュー**：4:3の大きなプレビューで画角を確認できます。前後のカメラも切り替えられます。
- **解像度を優先した保存**：選択中のカメラが提示する最大の写真寸法を要求し、HEIC（非対応ならJPEG）で写真ライブラリへ保存します。アプリ内で縮小・再圧縮してから保存することはありません。
- **撮影ごとの自動消音処理**：切り替えスイッチはなく、撮影のたびに自動で実行します。システムが対応していればAppleの公式APIを使い、対応していなければ実験的な処理を使います（[詳しく](#シャッター音の扱い)）。
- **デジタルズーム**：倍率ボタン、調整バー、ピンチで操作できます。
- **保存状況の表示と再試行**：保存状況を表示し、保存に失敗したときは再試行できます。アプリを終了すると、まだ保存されていない写真は失われます。
- **限られた権限**：通常の撮影で使うのは、カメラと、写真ライブラリへの追加のみの権限です。アプリ独自のネットワーク通信、広告、分析・追跡機能はありません。

## しくみと制約

### シャッター音の扱い

撮影のたびに、次のどちらかを自動で行います。オン・オフを切り替える設定はありません。

| 条件 | 処理 | 種類 |
| --- | --- | --- |
| `isShutterSoundSuppressionSupported` が true | `isShutterSoundSuppressionEnabled` を有効にする | Appleの公式API |
| 上記に該当しない | 撮影前後の通知内で `AudioServicesDisposeSystemSoundID(1108)` を呼ぶ | 実験的な処理 |

`AudioServicesDisposeSystemSoundID` 自体は公開APIです。**ただし、ID `1108` を使って撮影音を抑える方法は、Appleが文書化した消音の仕組みではありません。** この処理は [ExperimentalShutterSilencer.swift](QuietCamera/ExperimentalShutterSilencer.swift) に分けて実装しています。

- 処理を実行することと、実際に無音になることは別です。戻り値が `0` でも、消音に成功したとは判断していません。
- 端末、OS、地域、撮影条件によっては音が鳴る可能性があります。OSのアップデートで動作が変わることもあります。
- 前面カメラにも同じ処理を適用していますが、前面での効果は実機で確認できていません。
- Appleがこの実装を承認していることも、App Store審査やAppleの契約・規約に適合していることも、確認していません。

参考：[Appleの撮影音抑制API](https://developer.apple.com/documentation/avfoundation/avcapturephotooutput/isshuttersoundsuppressionsupported)

### 画質と解像度

| 項目 | 設定 |
| --- | --- |
| 撮影 | `AVCapturePhotoOutput`、`.photo` プリセット |
| 要求する寸法 | 選択中のカメラが提示する最大の写真寸法 |
| 写真品質の優先度 | `.quality` |
| 圧縮品質 | `1.0` |
| 保存形式 | HEIC。非対応ならJPEG |
| アプリ内の縮小・再圧縮 | 保存前には行いません |

次の制約があります。

- **HEIC/JPEGは非可逆圧縮です。** 圧縮品質 `1.0` は、無劣化という意味ではありません。
- 画面に表示される最大解像度は、アプリが要求している値です。実際の保存結果は、機種、レンズ、照明、システムの処理などによって変わります。
- 純正カメラと同じ画像処理・画質や、すべての機種で24MP/48MPになることは保証しません。RAW/ProRAWには対応していません。
- 背面ではメインの広角カメラを使います。ズームはデジタルズームなので、倍率を上げると細部や保存解像度が落ちることがあります。画素数が同じでも、1×と同じ細部が残るわけではありません。
- 「さらに拡大」は、そのカメラが許可する上限まで倍率を上げてみる機能です。高倍率での画質や動作は、広くは検証していません。

<details>
<summary><strong>48MPの確認と遅延処理</strong></summary>

<br>

48MP対応の背面カメラを1×で使う場合は、要求した最大寸法を基準に写真を確認します。寸法が足りない写真は保存せず、エラーを表示します。確認するのは、完成画像なら実際の寸法、遅延処理のプロキシならシステムが返す完成予定の寸法です。ズーム中は解像度の低下を受け入れます。前面カメラには、この48MPの条件を適用しません。

遅延写真処理に対応した環境では、プロキシを `.photoProxy` として写真ライブラリへ渡し、仕上げはシステムが行います。**プロキシの寸法は、完成画像の寸法ではありません。また、完成予定の寸法を確認しても、処理後の画質が保証されるわけではありません。** 「写真アプリで仕上げ待ち」と表示された場合は、処理が終わってから「写真」の情報画面で寸法を確認してください。

参考：[Appleの遅延写真プロキシ](https://developer.apple.com/documentation/avfoundation/avcapturedeferredphotoproxy)

</details>

## 権限とプライバシー

| アクセス | 通常の撮影での扱い |
| --- | --- |
| カメラ | 撮影に使用 |
| 写真ライブラリ | **追加のみ**（`addOnly`）。既存の写真を読む権限は要求しません |
| 位置情報 | 要求しません |
| マイク | 使用しません（下記参照） |
| ネットワーク・広告・分析 | アプリ独自のものはありません |

写真ライブラリに保存した後のiCloud同期などは、端末の設定に従います。

以前のマイク・Live Photo実験のコードと、マイク権限の説明文はプロジェクトに残っています。ただし、この機能の有効フラグは `false` に固定されていて、撮影画面からは起動できません。通常の撮影でマイクやLive Photoを使うことはありません。

## インストール

### 必要なもの

- iOS 18.0以降のiPhone（実際に確認できた範囲は[確認済みの範囲](#確認済みの範囲)を参照）
- iOS 18以降のSDKを含み、接続するiPhoneのiOSに対応したXcodeが入ったMac
- 実機へインストールするためのApple Account

外部ライブラリ、追加パッケージ、サーバーは不要です。Simulatorだけでは、実際の撮影・消音・保存品質は確認できません。

### 自分のiPhoneに入れる手順

このリポジトリにはソースコードのみが含まれます。署名済みアプリ、開発者証明書、秘密鍵、プロビジョニングプロファイルは含みません。

1. [QuietCamera.xcodeproj](QuietCamera.xcodeproj) をXcodeで開きます。
2. **Xcode > Settings > Apple Accounts** で、自分のApple Accountにサインインします。
3. **TARGETS > QuietCamera > Signing & Capabilities** で **Automatically manage signing** を有効にし、自分の **Team** を選びます。
4. **Bundle Identifier** の `com.example.QuietCamera` は公開用の仮の値です。自分だけの識別子に変更してください（例：`com.example.myuniqueid.QuietCamera`）。
5. iPhoneをMacに接続してロックを解除し、必要に応じてコンピュータを信頼します。求められた場合は、iPhoneの **設定 > プライバシーとセキュリティ > デベロッパモード** を有効にします。
6. Xcodeでスキーム **QuietCamera** と接続したiPhoneを選び、**Run（⌘R）** を押します。
7. 未信頼のデベロッパと表示された場合は、iPhoneの **設定 > 一般 > VPNとデバイス管理** から、自分の開発者Appを信頼・検証します。
8. カメラへのアクセスと写真の追加を許可して撮影し、保存結果を「写真」で確認します。最初は、音が出ても問題のない場所で試してください。

> [!NOTE]
> 無料のPersonal Teamでは、プロビジョニングプロファイルが発行から**7日間**で期限切れになります。期限が切れたら、同じApple AccountとBundle Identifierで再ビルド・再インストールしてください。詳しくは[Appleの説明](https://developer.apple.com/help/account/basics/about-your-developer-account)をご覧ください。

自分の署名設定を加えたうえで再公開する場合は、Team ID、端末情報、証明書、個人用の設定やログが含まれていないことを確認してください。
